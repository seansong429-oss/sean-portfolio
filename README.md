# Sean Song 个人网站

[在线访问](https://seansong429-oss.github.io/sean-portfolio/) · 使用原生 HTML、CSS 和 JavaScript 构建。

网站展示 Sean Song 的简介、关注方向和真实作品「去野」，提供邮箱及 GitHub 联系方式。

## 文件

- `index.html`：页面内容与分享信息
- `style.css`：响应式布局及浅深色主题
- `script.js`：导航菜单和主题切换
- `assets/quye-preview.webp`：去野线上页面截图
- `assets/share-preview.jpg`：社交分享预览图
- `assets/favicon.svg`：站点图标

## 发布
